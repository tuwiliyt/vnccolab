# VNC Colab / Linux Remote Desktop

One-shot command untuk mengaktifkan Remote Desktop (XFCE4 + noVNC + Cloudflare Tunnel) pada Ubuntu / Google Colab.

## 🚀 Jalankan One-Shot Command:

```bash
curl -sL https://raw.githubusercontent.com/tuwiliyt/vnccolab/main/vnc.sh | bash
```

### Kustom Password:
```bash
curl -sL https://raw.githubusercontent.com/tuwiliyt/vnccolab/main/vnc.sh | bash -s -- password_anda
```
